# An Evening for Shubhm

Static React + three.js site, published with GitHub Pages.

1. Upload everything in this folder to the root of a GitHub repo (branch `main`).
2. Repo Settings -> Pages -> Source -> **GitHub Actions**.
3. Wait for the "Publish birthday website" action to finish; the link appears in Settings -> Pages.

Wishes are sent through Formspree (endpoint is in `app/page.tsx`, function `shareWish`).
